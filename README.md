# JGB Business Hub - Sales Monitoring V2

This repository contains the new JGB Business Hub Accounting System V2.

## Deployment

The accounting system is located in the `accounting-v2/` directory.

You can access the live version here:
[https://jgkarunungan.github.io/sales-monitoring-v2/accounting-v2/](https://jgkarunungan.github.io/sales-monitoring-v2/accounting-v2/)

## Project Structure

- `accounting-v2/`: Core web application files (HTML, CSS, JS).
- `accounting-v2/js/`: JavaScript modules and services.
- `accounting-v2/css/`: Styling overrides.

## Technology Stack

- HTML5 / CSS3 / Vanilla JavaScript
- Firebase Web SDK v10
- Tailwind CSS
